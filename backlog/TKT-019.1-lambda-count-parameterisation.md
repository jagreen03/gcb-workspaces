# Objective

**Sub-story 1 of EPIC [[TKT-019]] (Optical WDM Transport), the first PHY-scaling
build against the ratified [[GCB-034]] dual-regime contract.**

Make the **DWDM wavelength count and the per-λ I/Q lane assignment real
parameters** across the four transport-plane modules —
`gcb_wavelength_router`, `gcb_dwdm_tx_packager`, `gcb_dwdm_deskew`,
`gcb_rx_digital_recombiner` — with `gcb_bitplane_tx_mapper` **frozen and
untouched** (`gcb-wiki/13`, TKT-015). Every wavelength count must still
reconstruct **bit-exact** per the `gcb-wiki/13` `S_ij` / `Y` INT16 algebra.

## What the parent contract requires of the PHY

[[GCB-034]] closed `done | green` with a **dual-regime** transport contract.
Its wavelength implications ([[GCB-037]] V4):

* **Mode A** (FFN throughput, INT8 `q_tile`, ≈ 4.74 Gbps): **1 λ**, link
  closes on a single sub-10 G lane.
* **Mode B** (K-split + INT32 partials, long-context / latency-critical decode):
  ≈ 4·P λ per K-split link → **≈ 60 λ at the P = 4 accumulator** (~a full
  C-band comb).
* **The PHY is provisioned for Mode B.** Every parameterised module must
  elaborate, lint, elaborate on Yosys 0.68, and reconstruct bit-exact across a
  swept **`N_LAMBDA` = 2 → ≥ 60**.

The 6-bit `WAVELEN_ID_W` in `gcb_dwdm_pkg` (`≤ 64 DWDM colors`) already sizes
the wavelength id for this range; this sub-story makes the datapath modules use
it.

## Current state — what is hard-wired

| module | wavelength handling today | change |
|---|---|---|
| `gcb_wavelength_router` | **hard-wired 2 colours** — `color_0_i/q`, `color_1_i/q`; fixed map `color 0 : I=plane 0, Q=plane 1 · color 1 : I=plane 2, Q=plane 3`. Only `NUM_OPERANDS` / `REG_OUT` are params | replace the two named colour buses with an `N_LAMBDA`-wide I/Q bus; make the plane→(λ, axis) map a parameter |
| `gcb_dwdm_tx_packager` | `NUM_COLORS` **is** a param (default 8), `WAVELEN_BASE` static contiguous map; `wl_ovr` dynamic override exists | prove it composes and routes correctly at `NUM_COLORS = N_LAMBDA` up to ≥ 60; align the param name / wavelength-id map with the router |
| `gcb_dwdm_deskew` | per-colour elastic FIFO array; barrier sync pops all colours together | parameterise the FIFO-instance count to `N_LAMBDA`; the "all colours !empty" barrier already generalises |
| `gcb_rx_digital_recombiner` | reconstructs one operand-pair's `S_ij` / `Y` from 16 `l_ij` + marginals; `K_MAX` param | parameterise the **lane (recombiner-instance) count** to `N_LAMBDA / 2` (each operand-pair rides 2 λ); the per-lane `S_ij` / `Y` math is the **invariant — unchanged** |
| `gcb_bitplane_tx_mapper` | 4 raw antipodal planes per INT4 operand | **FROZEN** — no port, parameter, or logic change |

## The parameterisation

### `N_LAMBDA` and `LAMBDA_MAP`

* **`N_LAMBDA`** (int, default = the current fixed count so existing
  instantiations are unchanged: `2` for the router, `8` for the packager;
  a shared `gcb_dwdm_pkg::N_LAMBDA_DEFAULT` may be introduced). Range checked
  `2 ≤ N_LAMBDA ≤ 64` (`WAVELEN_ID_W`); even (I/Q pairing) unless a later story
  adds odd-λ handling.
* **`LAMBDA_MAP`** — the per-λ I/Q lane assignment: for wavelength `w`, which
  `(operand_group, plane, axis ∈ {I,Q})` it carries. Default rule reproduces
  today's map (`w = 2g` → group `g` planes `{0→I, 1→Q}`; `w = 2g+1` → planes
  `{2→I, 3→Q}`), so `N_LAMBDA = 2` is bit-identical to the pre-change router.
  Expressed as a `localparam`-buildable table or a documented rule, not a magic
  constant.
* The **`gcb-wiki/13` `S_ij` / `Y` reconstruction algebra is the invariant.**
  Whatever `LAMBDA_MAP` chosen, the receiver must recover the exact INT16 dot
  product `S_ij = (L_ij + 2·M_a[i] + 2·M_b[j] − K)/4`,
  `Y = Σ W_i·W_j·S_ij`, `W = {1, 2, 4, −8}`.

### Constraints

* `gcb_bitplane_tx_mapper` byte-identical (frozen interface; TKT-015 /
  `gcb-wiki/13`). Scaling happens **around** it.
* Pure SV-2017; `bash sim/lint.sh` exit 0 (`-Wall`, only
  `-Wno-DECLFILENAME -Wno-UNUSEDPARAM`) with every new/changed top;
  `sv2v` → Yosys **0.68** elaboration clean and **latch-free**
  (`select -assert-count 0 t:$dlatch t:$dlatchsr t:$sr`).
* intent.md Invariant #1 (non-positional optical compute): I and Q stay
  orthogonal in the optical field; **no analog positional weighting** anywhere
  on the link — bit weights `{1, 2, 4, −8}` are applied only in
  `gcb_rx_digital_recombiner`.
* PBG / Cyclopter prompt-layer protocols stay out of the RTL repo
  (`gcb-wiki/04`).

## AI Orchestration Priorities (PBG Evaluation)

Taxonomy: **Purple** strategic net-new capability · **Blue** sustainable
engineering on the target architecture · **Green** the gap cleanly closed,
in-spec · **Yellow** expedient workaround, architectural drift · **Red** brittle
debt · **Light-gray** low-signal / accept-the-limitation.

**Target: Green through Blue-grade engineering** — the four modules take a real
`N_LAMBDA`, and the `gcb-wiki/13` algebra still reconstructs bit-exact at every
count from 2 to ≥ 60.

* **Green (target):** `N_LAMBDA` + `LAMBDA_MAP` real parameters across the four
  modules; `N_LAMBDA = 2` bit-identical to today; a Cocotb λ-sweep regression
  (`N_LAMBDA ∈ {2, 4, 8, 16, 32, 48, 60, 64}`) reconstructing **bit-exact vs a
  frozen `gcb-wiki/13` Python reference** on random INT4 operand vectors;
  `gcb_bitplane_tx_mapper` untouched; `sim/lint.sh` exit 0; `sv2v` → Yosys 0.68
  elaboration clean + latch-free at each swept `N_LAMBDA`.
* **Blue:** a frozen `sim/cocotb/gcb_wdm_ref.py` implementing the doc-13
  `S_ij` / `Y` algebra (reused by every later TKT-019.x); per-module Cocotb TBs
  (`gcb_wavelength_router`, `gcb_dwdm_deskew`, `gcb_rx_digital_recombiner`, and
  the packager) each proven against it before the top sweep; the sweep wired
  into `sim/lint.sh` + a guarded `sim/run_tb.sh` stanza + a
  `sim/cocotb/Makefile.wdm_lambda_sweep`; the changed modules added to
  `sim/yosys068_bless/` as new golden `*.stat` with the latch-free check; a
  line-number traceability note (module ↔ `gcb-wiki/13` equation).
* **Yellow (reject):** bumping the colour count with a magic constant and a TB
  that still only checks 2 colours; `N_LAMBDA` a parameter in name but the
  reconstruction only validated at the default.
* **Red (reject):** altering `gcb_bitplane_tx_mapper`'s ports/logic or the
  doc-13 `S_ij` / `Y` algebra to make more wavelengths "fit"; a recombiner that
  passes only because the plane→λ map is the trivial identity; applying any
  positional weight on the optical side.
* **Purple:** the epic's stated emergence — **the same TKT-015 Tx doctrine and
  the TKT-016 `gcb_max_reduce` (QAM slicing) that documented the 2-colour link
  now parameterise the N-colour link with no new encoding math.** Each sweep
  point closes with a PBG vector the Cyclopter scavenger (TKT-013) ingests.
* **Light-gray:** leaving the link hard-wired at two colours — caps the demo's
  transport story and blocks Mode B of the ratified contract.

## The "Green" Target

1. `gcb_wavelength_router`, `gcb_dwdm_tx_packager`, `gcb_dwdm_deskew`,
   `gcb_rx_digital_recombiner` each take **`N_LAMBDA`** (and the router +
   recombiner take **`LAMBDA_MAP`**); `N_LAMBDA = 2` reconstructs bit-identically
   to the pre-change RTL. `gcb_bitplane_tx_mapper` **unchanged**.
2. `sim/cocotb/gcb_wdm_ref.py` — frozen Python `gcb-wiki/13` `S_ij` / `Y`
   reference; per-module Cocotb TBs prove each of the four modules against it.
3. `sim/cocotb/Makefile.wdm_lambda_sweep` + `test_wdm_lambda_sweep.py` — sweeps
   `N_LAMBDA ∈ {2, 4, 8, 16, 32, 48, 60, 64}`, drives random INT4 operand
   vectors through mapper → router → packager → deskew → recombiner, asserts
   `Y` bit-exact vs `gcb_wdm_ref.py` at every count; prints
   `RECONSTRUCT OK  |  N_LAMBDA=… |  <n> vectors`.
4. `bash sim/lint.sh` exit 0 with every new/changed top; `sv2v` → Yosys 0.68
   elaboration **0 problems / latch-free** at each swept `N_LAMBDA`; new
   `sim/yosys068_bless/{wavelength_router,dwdm_deskew,rx_digital_recombiner}.stat`
   + `SUMMARY.md` rows.
5. Wired into `sim/lint.sh`, `sim/run_tb.sh` (guarded stanza), and the manifest
   `regression_gates`. Diff confined to the four transport modules + the new
   cocotb infra + the sim-list edits + the bless additions.
6. Each swept `N_LAMBDA` recorded with its PBG vector for Cyclopter (TKT-013).
